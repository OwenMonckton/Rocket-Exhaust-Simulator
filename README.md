## Data

The chemistry runs on NASA's thermodynamic database, thermo.inp, as distributed with NASA CEA (https://github.com/nasa/cea) under the Apache License 2.0. The data the simulator uses, src/physics/chem/thermo.json, is derived from that file; the NASA notice is in src/physics/chem/THERMO-NOTICE.txt and the licence text beside it in src/physics/chem/LICENSE-APACHE-2.0.txt.
